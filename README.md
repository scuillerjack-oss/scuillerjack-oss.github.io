# scuillerjack-oss.github.io

Racine du domaine GitHub Pages du studio JS GAMES. Sert uniquement à :
- `app-ads.txt` : exigé par AdMob **à la racine du domaine** (https://scuillerjack-oss.github.io/app-ads.txt) ;
- `index.html` : renvoie vers le vrai site du studio, https://scuillerjack-oss.github.io/Jsgames/ (dépôt `Jsgames`, J majuscule).

Ne pas supprimer ce dépôt : sans lui, AdMob ne trouve plus `app-ads.txt` et limite la diffusion des publicités.
